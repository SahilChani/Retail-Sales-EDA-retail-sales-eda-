# 📊 Retail Sales Exploratory Data Analysis (EDA)
This repository contains a complete Exploratory Data Analysis (EDA) project on a synthetic retail sales dataset comprising over 10,000 transactions. The goal of this project is to uncover patterns, customer behavior trends, and actionable business insights.
## 🚀 Key Features
- **Data Cleaning & Inspection:** Handling missing values and ensuring correct data types.
- **Descriptive Statistics:** Calculating mean, median, mode, and standard deviation for all numerical columns.
- **Time Series Analysis:** Visualizing monthly and quarterly sales trends using Matplotlib.
- **Demographic Profiling:** Analyzing customer age groups and spending habits by gender using Seaborn.
- **Correlation & Advanced Insights:** Annotated heatmaps and custom day-of-week analysis to find non-obvious patterns.
## 📂 Repository Structure
- `data/` : Contains the generated dataset (`retail_sales.csv`).
- `retail_sales_eda.ipynb` : The fully executed Jupyter Notebook with all code, charts, and markdown observations.
- `build_notebook.py` : The Python script used to programmatically generate the environment.
## 💡 Business Recommendations
Based on the analysis, this notebook concludes with three specific, data-driven actionable business recommendations (e.g., shifting marketing spend based on day-of-week category surges).
## 🛠️ Tech Stack
`Python` | `Pandas` | `Matplotlib` | `Seaborn` | `Jupyter Notebook`
